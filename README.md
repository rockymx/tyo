# TyO - Directorio de Enlaces Especializados

Un directorio moderno y especializado de recursos médicos y ortopédicos construido con Next.js.

## 🚀 Características

- **29 categorías especializadas** de recursos médicos
- **Búsqueda en tiempo real** con filtrado inteligente
- **Sistema de favoritos** con persistencia local
- **Modo claro/oscuro** con transiciones suaves
- **Diseño responsive** optimizado para móviles
- **Modal promocional** interactivo
- **Accesibilidad mejorada** con navegación por teclado

## 🛠️ Tecnologías

- **Next.js 14** - Framework React moderno
- **TypeScript** - Tipado estático
- **CSS Variables** - Temas dinámicos
- **Font Awesome** - Iconografía
- **Google Fonts** - Tipografía (Inter)

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/tu-usuario/tyo-directory.git

# Instalar dependencias
cd tyo-directory
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build

# Exportar sitio estático
npm run export
```

## 🏗️ Estructura del Proyecto

```
src/
├── app/                 # App Router de Next.js
├── components/          # Componentes React
├── contexts/           # Context providers
├── hooks/              # Hooks personalizados
├── lib/                # Utilidades
├── types/              # Definiciones TypeScript
└── data/               # Configuración JSON
```

## 📱 Funcionalidades

### Búsqueda Inteligente
- Búsqueda en tiempo real con debouncing
- Filtrado por título, categoría y descripción
- Historial de búsquedas

### Sistema de Favoritos
- Agregar/quitar favoritos con un clic
- Persistencia en localStorage
- Vista filtrada de favoritos

### Temas
- Modo oscuro (por defecto)
- Modo claro
- Transiciones suaves entre temas

### Responsive Design
- Optimizado para móviles
- Header adaptativo
- Grid responsive
